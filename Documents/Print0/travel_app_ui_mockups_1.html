Screens ↔ AD tech requirements

The brief (p.7) requires integrating 5 technologies through one common backend. Here's how each screen covers them:
Mobile / Web
Android + Admin Web
Traveler mobile app (screens 1–6) + admin web. Users split naturally into travelers on mobile and operators on desktop.
Agentic AI
AI Agent
Extracts places from guides, validates locations, optimizes routes (screens 2, 4) — the AI Agent from the use case diagram.
Machine Learning
Route / NLP
NLP place extraction, route-order optimization, travel-time prediction (screens 2, 4).
Data Visualisation
Map + Dashboard
Route on map (screen 5) + admin charts. Note: the demo must distinguish report vs. dashboard.
Common Backend
Spring Boot + MySQL
All clients share one backend API — a work-as-a-whole, with one component deployed on the cloud.
